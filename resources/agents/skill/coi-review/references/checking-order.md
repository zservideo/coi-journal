# Checking order and renewal diary

1. Write the project requirements down, per trade, before collecting anything.
2. Read each certificate against those requirements, line by line.
3. Ask for the endorsements behind every requirement the certificate claims to meet.
4. Check the carrier's license (state insurance department or NAIC Consumer Insurance Search, https://content.naic.org/cis_consumer_information.htm) and the named insured.
5. Diary every expiration date; request renewals with endorsements 30 days before.
6. Check again at renewal, at substantial completion and before final payment.

See https://coijournal.com/reports/reading-a-coi-against-requirements/ and https://coijournal.com/reports/fixing-gaps-brokers-gcs/
